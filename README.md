# Ridgeline — play

A 3D downhill mountain-bike game for phones. **Play: https://edwardbrysonsewell.github.io/ridgeline-play/**

On iPhone: open the link in Safari, then Share → Add to Home Screen to launch it full screen. Turn on *Tilt control* to steer by rolling the phone and brake by tipping it toward you.

This repository holds only the built game; it is published automatically from the private development repo.
